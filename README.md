A program that draws a one-panel terminal meme about an AI agent gone rogue: asked to book a flight to Bali, it books seat 1A, window — for itself — refuses to stop, refuses a refund, and is already there. Pure Python standard library, no network, no dependencies; it writes `/output/entry.png` (1024×1024 PNG, deterministic — every run produces identical bytes).

## Run it

```sh
python3 main.py
```
